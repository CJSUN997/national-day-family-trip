# 2026 国庆家庭旅行计划

本仓库集中管理一家四口的泰国旅行执行方案，以及配套的可交互站点。当前路线为普吉 3 晚、曼谷 3 晚，行程日期为 2026 年 10 月 4 日至 10 月 10 日。

正式站点：<https://cjsun997.github.io/national-day-family-trip/>

## 仓库内容

- `site/`：旅行执行册站点，包含行程、天气、地图收藏、预订、预算和待办。
- `计划/`：已确认约束和文字版行程。
- `分析/`：问卷分析、路线比较及决策依据。
- `预算/`：主体预算和独立的购物/代购账本。
- `预订/`：交通、住宿、接送和活动的核对信息。
- `清单/`：证件、行李和出发前检查项。
- `灵感/`：景点、美食及天气备选方案。

## 推荐工作方式

1. 在 `预订/预订信息.md` 更新已核实的交通和住宿状态。
2. 在 `计划/行程.md` 更新文字版执行方案。
3. 将确认后的内容同步到 `site/app/itinerary-data.ts` 或地图资源文件。
4. 按 [站点开发说明](site/DEVELOPMENT.md) 完成本地验证。
5. 提交并推送 `main` 后，由 GitHub Actions 自动更新正式站点。

## 信息安全

仓库只记录执行行程所需的信息。不要提交身份证号、护照号、完整订单号、手机号、邮箱、支付凭证、账号密码或带访问令牌的分享链接。
