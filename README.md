# 国庆旅行计划

这个仓库用于集中管理国庆旅行的行程、预算、预订信息和出行清单。

## 快速开始

1. 在 `计划/行程.md` 中确定目的地和每日安排。
2. 在 `预算/预算.csv` 中记录预计与实际支出。
3. 在 `预订/预订信息.md` 中登记交通、住宿和门票。
4. 出发前逐项检查 `清单/出行清单.md`。
5. 将攻略、餐厅和备选地点放进 `灵感/备选方案.md`。

## 目录

- `计划/`：旅行概览与每日行程
- `预算/`：预算和实际花费
- `预订/`：交通、住宿、门票等预订记录
- `清单/`：证件、行李和出发前待办
- `灵感/`：景点、美食及雨天备选方案

## 使用 Git 管理变更

每完成一轮重要调整就提交一次，例如：

```text
规划初版行程
更新酒店预订信息
记录实际交通支出
```

> 安全提示：不要提交身份证号、护照号、支付凭证、完整订单号或账号密码。
