# 出行清单

## 出发前

- [ ] 确认所有预订时间与姓名
- [ ] 检查天气、交通和景区公告
- [ ] 告知家人行程与紧急联系人
- [ ] 关闭不必要的电器，处理门窗和垃圾
- [ ] 为手机、充电宝和相机充电

## 证件与支付

- [ ] 身份证/护照及必要证件
- [ ] 银行卡和少量现金
- [ ] 电子票据与预订确认
- [ ] 驾照（如需自驾）

## 电子设备

- [ ] 手机与充电器
- [ ] 充电宝
- [ ] 耳机
- [ ] 相机及存储卡（可选）

## 衣物与日用品

- [ ] 换洗衣物
- [ ] 舒适步行鞋
- [ ] 雨具与防晒用品
- [ ] 洗漱用品
- [ ] 常用药与创可贴

## 回程前

- [ ] 检查酒店房间和保险柜
- [ ] 确认返程班次状态
- [ ] 整理发票与支出记录
